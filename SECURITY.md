# Security

Embark is a web browser, so security bugs matter. Please don't report them in public issues.

## Reporting a vulnerability

Use [private vulnerability reporting](https://github.com/chiranjeebhub/embark-browser/security/advisories/new)
on GitHub. Include what you found, how to reproduce it, and which engine (WebKit or Chromium)
and macOS version you used. You'll get a reply as soon as the maintainer can look at it.

Bugs in Chromium itself should go to the [Chromium bug tracker](https://issues.chromium.org/),
and bugs in CEF to the [CEF issue tracker](https://github.com/chromiumembedded/cef/issues).

## Supported versions

Embark is in early development. Only the latest `main` gets fixes.
