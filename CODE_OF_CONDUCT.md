# Code of Conduct

Embark follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be welcoming and respectful, give and accept constructive feedback, and focus on
what is best for the project and the people using it. Harassment, personal attacks and
insulting or demeaning comments are not acceptable, in issues, pull requests or anywhere else
you represent the project.

## Reporting

If someone's behavior is a problem, contact the maintainer, [@chiranjeebhub](https://github.com/chiranjeebhub),
privately on GitHub. Reports are kept confidential. The maintainer may edit or remove comments,
issues and pull requests, and may block people who don't follow this code.
